# Steel OS: the one-click Steel Apps list.
# Read at build time by build_files/portal/make-portal.py (the Steel Apps tab
# of the Steel OS Portal) and build_files/portal/make-bazaar.py (the Curated
# page of the App Store). One list, both places.
#
# Format: flatpak-id | display name | one-line description | category
# Categories, in the order they are shown:
#   Everyday, Work, Creative, Games and Streaming, Developer
# All IDs verified on Flathub. Installs come from Flathub.
