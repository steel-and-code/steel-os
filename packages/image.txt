# Steel OS: rpm packages added to the system image (read by build_files/build.sh)
# Fedora package names. One per line. Only system pieces go here; apps are
# Flatpaks (see flatpaks-default.txt and steel-apps.txt).


# Printing for older, non-driverless printers (STEEL-3 findings).
hplip
gutenprint-cups

# Makes this machine appear in Windows Explorer's Network, and helps Dolphin
# find Windows PCs (STEEL-3 findings).
wsdd

# Verify after the first boot whether Bazzite already includes these KDE apps.
# Add any that are missing:
#   ark kate okular skanpage spectacle gwenview kolourpaint print-manager

# Virtual machines out of the box: the libvirt service, QEMU/KVM, the default
# NAT network and a software TPM (for Windows 11 guests). Bazzite does not
# ship these. Virtual Machine Manager itself is a Steel Apps one-click Flatpak.
libvirt-daemon-kvm
libvirt-daemon-config-network
swtpm

# First-login setup dialogs (STEEL-35). Usually already part of KDE.
kdialog

# Password reset window before the login screen (STEEL-36): a minimal
# full-screen session, and text-mode dialogs as a fallback.
cage
dialog

# Login screen (STEEL-36): SDDM with the Breeze theme, so Steel OS can add
# "Forgot your password?". Replaces Fedora 44's Plasma Login Manager.
sddm
sddm-breeze
sddm-wayland-plasma

# Printers and scanners, the common brands without hunting for drivers (STEEL-38).
# HP: hplip (above). Canon and Epson: gutenprint-cups (above) and driverless.
# Brother lasers: brlaser. Most printers since about 2015: driverless (IPP
# Everywhere / AirPrint), over the network or USB (ipp-usb).
printer-driver-brlaser
ipp-usb
cups-browsed
foomatic
foomatic-db-ppds
splix
# Plug in a USB printer and it is set up by itself.
system-config-printer-udev
# Scanning: Skanpage app, SANE drivers (Canon PIXMA, Epson, many more),
# Epson scanner firmware, and driverless network scanners (eSCL / WSD, used by
# most Brother, Canon, Epson and HP models with Wi-Fi).
skanpage
sane-backends-drivers-scanners
sane-airscan
iscan-firmware

# Windows networking (STEEL-39): be seen by Windows PCs (wsdd, above), open
# their shares in Dolphin, and share a folder with a right-click (Samba
# usershares + Dolphin's Share tab).
samba
samba-usershares
kdenetwork-filesharing

# VPN (STEEL-39): import a VPN from System Settings with no terminal.
# WireGuard is built into NetworkManager and Plasma; these add OpenVPN (most
# VPN services), Cisco AnyConnect and compatible (OpenConnect), and Cisco
# IPsec (vpnc), the common work VPNs.
plasma-nm-openvpn
plasma-nm-openconnect
plasma-nm-vpnc

# Gaming devices (STEEL-32). Bazzite already includes the drivers for the Xbox
# wireless adapter (xone), Razer devices (openrazer), and Thrustmaster,
# Logitech and Fanatec racing wheels. These add the tools:
#   Solaar:          Logitech wireless keyboards, mice and receivers
#   ratbagd:         gaming-mouse settings (buttons, DPI, lights) for Piper
#   AntiMicroX:      use a controller in games that only know keyboard and mouse
#   jstest-gtk, linuxconsoletools: test and calibrate joysticks and flight sticks
#   zenity:          dialogs used by the Star Citizen LUG Helper
solaar
solaar-udev
libratbag-ratbagd
antimicrox
jstest-gtk
linuxconsoletools
steam-devices
zenity

# Steel Shield, built-in virus protection (STEEL-53): the ClamAV scanner, its
# hourly definitions updater, and file-change watching for Downloads.
clamav
clamav-freshclam
inotify-tools

# Developer tools built in (Katana test, Rodger): Neovim, with the nvim command.
neovim
# git and ripgrep (the rg command), asked for in a report (2026-10-24). Bazzite
# already ships git; listing it keeps it if that ever changes. Other command-line
# tools stay a choice, through Homebrew (Bazzite ships it; see brew.txt).
git
ripgrep

# Steel & Code Forge one-click install (STEEL-25): its Python environment
# and the password-store command that keeps its OpenRouter key.
python3-pip
libsecret

# One-window forms (security questions on one page, T 2026-10-17).
yad

# The Steel Shield app window (T, 2026-10-18): Qt for Python. Without it
# Steel Shield falls back to its simple menus.
python3-pyside6
