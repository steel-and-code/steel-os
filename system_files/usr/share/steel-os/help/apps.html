Installing and removing apps

Apps install with one click, update themselves, and never touch the system files.

The quickest way: Steel Apps

  1. Open the Steel OS Portal from the taskbar.
  2. Click the Steel Apps tab. Apps are grouped: Everyday, Work, Creative, Games and Streaming. Code editors, AI coding tools (Steel & Code Forge, Antigravity, VS Code) and virtual machines are on the Developer tab. AI assistants (Alpaca, Newelle, GPT4All, and Copilot, ChatGPT, Claude and Gemini) are on the AI tab.
  3. Click an app, then Install. A small window shows the download; press Enter to close it when it says so.
  4. The app appears in the start menu.

Thousands more: the App Store

Open App Store from the start menu or the taskbar. The Curated page starts with the Steel Apps; Search finds anything else. Click Install.

Keep apps up to date: install from the App Store or the Portal

Install apps from the App Store or the Portal, not from websites, so they update themselves. Steel OS checks every App Store and Portal app for updates once a day and installs them quietly in the background, Zoom, Chrome, Slack and Discord included. Nothing to click, no restart.

A program downloaded from a company's own website (a .deb, .rpm or AppImage file) never updates by itself: you'd have to download it again every time. If an app is in the App Store, use that one.

Removing an app

  • In the Portal: click the app, then Uninstall.
  • Or in the App Store: Library, find the app, Remove.

OneDrive, Google Drive and Dropbox

Microsoft doesn't make a OneDrive app for Linux, so Steel OS gives you two ways, both one click in the Steel OS Portal, Steel Apps, Everyday:

  • OneDrive adds OneDrive to the start menu. It opens in Firefox: all your files, plus Word, Excel and PowerPoint online. The simplest choice.
  • RClone Manager shows OneDrive, Google Drive, Dropbox and others as folders in the file manager. Open it, choose Add remote, pick OneDrive and sign in with your Microsoft account in the browser. Files open on demand rather than being kept as a full offline copy like on Windows, so you need to be online to open them.

Dropbox also has its own app in Steel Apps, which keeps an offline copy.

Already installed for you

Firefox and LibreOffice (Word, Excel and PowerPoint files) are there from the start. Obsidian, Zed and ProtonPlus install themselves a few minutes after your first start, as long as you are online. OBS Studio, Kdenlive and Moonlight are one click in the Steel OS Portal, Steel Apps.

For developers

Built in: git, ripgrep (the rg command) and Neovim (nvim), in Konsole, the terminal. Code editors and AI coding tools are on the Developer tab of Steel Apps. For other command-line tools, Homebrew is built in too: open Konsole and type, for example, brew install jq fd gh. Tools installed with Homebrew stay when Steel OS updates.

Windows programs (.exe files) don't run directly. Most have a Linux version in the App Store. Windows games run through Steam or Lutris; see Gaming.
