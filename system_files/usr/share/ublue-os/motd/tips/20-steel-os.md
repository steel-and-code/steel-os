**Super+Enter** opens this terminal. **Alt+C** copies and **Alt+V** pastes inside it.
**Super+Shift+Enter** opens Firefox. **Super+1** to **Super+4** switch desktops.
Steel OS updates itself every **Tuesday just after midnight**. The previous version is always in the boot menu if you need it.
*Update break something?* Restart, and pick the second Steel OS entry in the boot menu.
Apps install from the **App Store** in the start menu. Most come as sandboxed Flatpaks.
Built on Bazzite and Fedora; source code at steel-os.org/source
